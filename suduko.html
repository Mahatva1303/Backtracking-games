Backtracking concept in Sudoku Solver

Backtracking is a general algorithmic technique that incrementally builds candidates for a solution and abandons (“backtracks”) a candidate as soon as it determines that the candidate cannot possibly lead to a valid solution. In a Sudoku puzzle, the goal is to fill a 9×9 grid so that every row, column, and 3×3 subgrid contains the digits 1 to 9 exactly once. Backtracking systematically tries numbers in empty cells, checking at each step whether the placement keeps the Sudoku rules valid..


Here’s how backtracking works in a Sudoku solver:

  • Start with the given Sudoku grid.
    Some cells are already filled; the rest are empty (represented as 0 or blank).
  • Find the first empty cell.
  • Try filling the cell with digits 1–9 one by one:
    • For each number, check whether it follows Sudoku rules:
    • The number is not already present in the same row.
    • The number is not already present in the same column.
    • The number is not already present in the same 3×3 subgrid.
  • If the number is valid, place it temporarily in the cell and move to the next empty cell (recursive step).
  • If no number fits, backtrack:
    • Remove (reset) the last filled number.
    • Try the next possible number for the previous cell..
  • Repeat this process until all cells are filled correctly or no valid configuration exists.
  • If the grid is completely filled, the Sudoku is solved
